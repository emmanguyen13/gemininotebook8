# Gemini Notebook Mastery K8 — 13-day publishing workflow

## Repository goal

One repository and one course site. Each day adds a new learning layer while preserving all previous days for review.

## Daily rhythm

1. Draft and review the day's email/content.
2. Add the new day to the course site.
3. Run the production build.
4. Commit with: `Day NN: short outcome`.
5. Push to GitHub `main` after review.
6. Publish the new site version.
7. Test the production link and send it to learners.

## Content contract for every day

- One observable outcome.
- One source-grounded core task.
- One quick win.
- One wow moment.
- Copy-ready prompts.
- Human Check.
- Facebook submission template.
- Completion criteria.
- A link back to prior days.
